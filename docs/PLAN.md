
# モード切り替えと機能
ノーマルモードは何もしない場合のモード
各モードに入るショートカットキーと、escape でノーマルモードに戻れる。

## ノーマルモード
基本は、縦に（列で）ウィンドウがタイリングされる。
このときのウィンドウ間、メニューバーとかの隙間も設定で変えられる。（最初は指定で OK）

### フォーカスの移動
ウィンドウのフォーカスも、ショートカットキー（ctrl+option+JKLI）で移動できる。

異なるモニター間のウィンドウのフォーカスも移動できる。
同じショートカットキーで。
例えば、モニター1 とモニター2 が横に並んでいたら、モニター1 の一番右のウィンドウにフォーカスがあって、そこから ctrl+option+L したら、モニター2 のウィンドウの一番左にフォーカスが移動するみたいな？
上下に設置されているやつだったら、ctrl+option+I と K でモニターをまたぐウィンドウのフォーカスも移動できる。

### ウィンドウの配置を変える
例えば、123 となっているものを、132 と変えるときなど。
ctrl+option+JKLI+shift で、今フォーカスされているウィンドウを左右上下に移動できる。
123 だったら、2 にフォーカスがある状態で ctrl+option+L したら、132 になる。

## ウィンドウ選択モード
ショートカットキー（ctrl+option+S）でウィンドウ選択モードに入れる。

### ウィンドウを結合して縦で割る
複数ウィンドウを選択できて、列でタイリングされているものを、1 つの列の中に、行で分割できる。
例えば、123 と列でならんでいたら、2 と 3 を選択して、1（23）みたいに、2 と 3 が縦で分割される。
ウィンドウ選択モードに入ったら、ctrl+option+JKLI でウィンドウを移動できて、enter で選択、backspace で選択解除。
ctrl+option+v で行分割。

### 複数ウィンドウの操作
例えば、1(23) となっているとする（2 と 3 は同じ列で、行で分割されている）。
これのとき、(23)1 としたいとき、23 を複数選択し、ctrl+option+JKLI+shift で動かすことができる。

## ギャップ選択モード
ctrl+option+G でこのモードに入れる。
ウィンドウ間の隙間、例えば 123 って並んでいたら、1 と 2 の間、2 と 3 の間など。
ここを選択できる。
	cギャップ選択時は、選択可能な隙間に半透明の太い線を表示させる。

### ウィンドウのリサイズ
ctrl+option+JKLI で移動し、enter で隙間を選択できる。
そして、ctrl+option+JKLI で隙間を動かすことで、ウィンドウのリサイズを行える。
リサイズが終わったら、enter で確定できる。

境界線そのものを掴んで動かす、というイメージ

## 仮想デスクトップ
aerospace などは、独自のワークスペース機能を持っていたが、今回作るものは違う。
mac 標準の、仮想デスクトップを使用する。
仮想デスクトップ間の移動や、ウィンドウを隣のデスクトップに送るとか、そういう作業もできるようにしたい。

仮想デスクトップの移動は、今フォーカスされているモニターで、ctrl+option+UO で移動できる。
ctrl+option+UO+shift で、隣の仮想デスクトップに今フォーカスしているウィンドウを送ることができる。横方向？しか動かせないので、サイクルできるようにする。

### ウィンドウ選択モードでの動作
複数ウィンドウを移動させたい時は、ウィンドウ選択モードに入って、ctrl+option+UO+shift で、仮想デスクトップに送れる。
例えば、行で分割されているウィンドウ 1 列を、そのまま移動させる、とかができる。

## モニター間のカーソル移動
もし隣のモニターにウィンドウが開かれていなくて、開きたいとき、隣のモニターにカーソルを移動させて、（自分の場合は raycast でアプリを開く）ウィンドウを開く必要がある。
この時にマウスを握る必要があるので、ctrl+option+MQ でモニター間をサイクル？で移動させたい。

Raycast などのランチャーを使う場合、マウスカーソルがある画面にランチャーが出るため、キーボードだけでカーソルを隣のモニターに飛ばす機能は、マウスを触る頻度を激減させる。
